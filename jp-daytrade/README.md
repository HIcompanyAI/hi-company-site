# 米国連動 日本株デイトレ・プランナー

前夜の米国市場(S&P 500 / NASDAQ 100 / SOX / ドル円 / ADR)の動きから、翌朝の東京市場で「どの銘柄を、どちら向きに、寄り成行で仕掛け、利確 +1.5%・損切り −1.0% の逆指値をどこに置くか」を毎朝自動で出すアプリです。夕方には実際の値動きで採点し、**「毎日 +1.5%」という目標に実際どれだけ届いているか**を、過去データの検証(バックテスト)と実運用の日誌の両方で可視化します。

> ⚠ 最初に読んでください
> - 「毎日 +1.5%」は年率換算で約 38 倍です。過去データの検証では、この水準に毎日届く確率はごく低く出るはずです。本アプリの価値は「届くかどうかを数字で確かめ、届かないなら目標や手法を修正できること」にあります。
> - 米国株の動きは日経先物の夜間取引で寄り付きまでにほぼ織り込まれます。寄り付き後に残る値幅は小さく、単純な順張り(米国高 → 日本株買い)は検証上むしろ負けやすい構造です。アプリは順張り・逆張り・ADR 理論値乖離・回帰モデルの 4 手法を同時に検証し、期待値がマイナスの手法では「見送り」を出します。
> - 投資助言ではありません。損失はすべて自己責任です。

## 仕組み

```
前夜の米国 (SPX/NDX/SOX/USDJPY/VIX, ADR) ──┐
                                           ├─ 07:35 JST  plan.mjs ──> data/latest.json ──> ダッシュボード(朝の売買プラン)
日本株の日足 (stooq / Yahoo, 無料) ─────────┘
                                              15:50 JST  plan.mjs --score ──> data/journal.json / performance.json(実績)
                                              日曜        plan.mjs --backtest ──> data/backtest.json(検証)
```

- **データ**: stooq(無料・キー不要)→ Yahoo Finance の順で日足を取得。API キーも LLM も不要で費用ゼロ。
- **モデル**: 銘柄ごとに、前夜の米国要因リターン(と ADR 理論値ギャップ)を説明変数に、「寄り付きギャップ」と「寄り→引けの日中リターン」をリッジ回帰で学習(直近 250 日、過去データのみ使うウォークフォワード)。
- **シグナル**: 予測日中リターン ÷ 残差の標準偏差(t 値)。上位 3 銘柄を採用。検証で期待値がマイナスの銘柄は除外。
- **執行ルール**(プランに毎日表示): 寄り成行 → 利確 +1.5% 指値と損切り −1.0% 逆指値を OCO で発注 → 15:25 までに未決済なら成行で手仕舞い。寄り付きが想定寄値から ±1% 以上ずれたら見送り。1 日の損失 2% で終了。
- **採点**: 当日の OHLC から「損切り到達 → 利確到達 → 引け」の順に保守的に判定(同日に両方到達なら損切り扱い)。

## 使い方

```bash
cd scripts
node plan.mjs --backtest     # 初回: 過去データで検証(数分)
node plan.mjs                # 朝: 本日のプラン
node plan.mjs --score        # 夕方: 採点
npm run open                 # http://127.0.0.1:8787/ でダッシュボード
node plan.mjs --sample       # ネット不要の動作確認(合成データ)
npm test
```

GitHub Actions(`.github/workflows/daily.yml`)で上記を自動化できます(private リポジトリ推奨)。パラメータは Variables で変更可: `TARGET_PCT`(既定 0.015)、`STOP_PCT`(0.01)、`TOP_K`(3)、`CAPITAL`(1000000)。

## ダッシュボードの見方

1. **本日の判断**: 「仕掛け」か「見送り」か。見送りはシグナルが弱いか、検証上の期待値がマイナスの場合。
2. **売買プラン**: 銘柄・方向・想定寄値・利確値・損切り値・株数。各行に過去検証での勝率・利確到達率。
3. **検証(バックテスト)**: 4 手法の勝率・利確到達率・平均損益・「1 日 +1.5% に届いた日の割合」・最大ドローダウン、資産曲線 vs 目標曲線(1.5% 複利) vs 日経 225。利確幅を 0.5〜3% に振ったときの到達率も表示。
4. **実績日誌**: 実運用(または紙上運用)の日次損益、目標との差。

## 証券会社側の設定

- 一日信用(デイトレ)口座。SBI・楽天・松井などは一日信用の手数料 0 円。空売り(ショート)も一日信用で可能
- 発注: 寄成(買い/売り建て)→ 約定後に OCO(利確指値 + 損切り逆指値)→ 15:25 に未決済分を成行決済
- 逆指値は「約定を確認するまで必ず入れる」。入れ忘れが最大のリスクです

    ├── plan.mjs                      朝プラン / 採点 / 検証

    ├── lib/backtest.mjs              ウォークフォワード検証・執行ルール
    ├── lib/synthetic.mjs             合成データ(テスト用)
    └── test/                         ユニットテスト
